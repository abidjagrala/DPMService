### 2. Added AI Settings Page

New settings page under AI Tools for configuring AI API providers (OpenAI, Gemini, DeepSeek, Anthropic, Groq, Mistral, Ollama, Custom).

#### Files Created
| File | Purpose |
|------|---------|
| `ai/models.py` | Added `AISettings` model (singleton pattern) |
| `ai/forms.py` | New file — `AISettingsForm` |
| `ai/views.py` | Added `ai_settings_view` (admin/superuser only) |
| `ai/urls.py` | Added `/ai/settings/` route |
| `ai/templates/ai/ai_settings.html` | Settings page template |
| `ai/migrations/0002_aisettings.py` | Migration for AISettings model |

#### AISettings Model Fields
| Field | Type | Default |
|-------|------|---------|
| `provider` | CharField (choices) | `openai` |
| `api_key` | CharField | `''` |
| `model_name` | CharField | `gpt-4o-mini` |
| `base_url` | URLField | `''` |
| `max_tokens` | PositiveIntegerField | `500` |
| `temperature` | DecimalField | `0.3` |
| `cache_ttl` | PositiveIntegerField | `86400` (24h) |
| `daily_budget` | DecimalField | `1.00` |
| `is_active` | BooleanField | `True` |

#### Supported Providers
- OpenAI (`gpt-4o-mini`, `gpt-4o`, `gpt-3.5-turbo`)
- Google Gemini (`gemini-2.0-flash`, `gemini-1.5-pro`)
- DeepSeek (`deepseek-chat`, `deepseek-coder`)
- Anthropic / Claude (`claude-3-5-sonnet`, `claude-3-haiku`)
- Groq (`llama-3.1-70b-versatile`, `mixtral-8x7b-32768`)
- Mistral AI (`mistral-small-latest`, `mistral-large-latest`)
- Ollama (local — `llama3`, `mistral`, `codellama`)
- Custom Provider (any OpenAI-compatible API)

After pulling these changes, run:
```bash
python manage.py migrate
python manage.py collectstatic --noinput
```

No new environment variables required — AI settings are managed via the `/ai/settings/` page after deployment.
